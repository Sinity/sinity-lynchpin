# AI-session boundary

Lynchpin does not read Polylogue archives, session products, verification receipts or live status. AI-session ingestion, queries and interpretation belong to Polylogue. Lynchpin has no Polylogue library or CLI dependency.

Lynchpin continues to read its other sources through their own adapters. ActivityWatch project attribution uses captured window titles. Campaign evidence uses task, runtime and forge observations. Chisel context contains tracker notes and owner verification records. Git and Chisel can inspect the Polylogue repository as source code, just like any other registered project.
